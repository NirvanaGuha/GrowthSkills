## 1. The thesis — why a *library* is worth $50/mo (and a prompt pack isn't)

A pile of disconnected prompts gets used twice and churns. A **library** retains because it behaves like an operating system for the growth function. Four design principles separate the two:

1. **System-of-record foundation.** A handful of "brain" skills (brand voice, ICP, positioning, competitive intel, offer/pricing) that every other skill *reads from*. Once a marketer invests an hour codifying their brand brain, every downstream skill gets sharper — and they're locked in, in the good way. This is the retention engine of the product.

2. **Chainable pipelines, not islands.** The killer demos are *chains*: keyword → SERP research → brief → draft → review → publish → internal-link → monitor → refresh. Each link is a skill; the chain is the moat. A marketer can run any single skill, but the value compounds when they run the whole assembly line.

3. **Opinionated frameworks baked in.** Not "write a blog post" but "write a comparison page using the alternative-page conversion structure, with the differentiation map filled from competitive intel." The library encodes *how good growth marketers actually work* — JTBD, AARRR, RICE, message-market fit, message-match, ICE — so a junior operator outputs senior work.

4. **Author/review separation (quality gates).** Every creation skill has a paired reviewer skill that grades against the brand brain and the brief. This is what makes the output trustworthy enough to ship without a human rewrite — and it's the hardest thing to copy.

> **Positioning line:** *"The entire growth marketing department, as a library of AI skills. Codify your brand once; run the whole funnel forever."*
